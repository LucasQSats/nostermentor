O Nostermentor precisa de JavaScript

Primeiro, recarregue a página (F5). Às vezes o Tor Browser abre o arquivo antes de estar pronto e o painel fica parado neste aviso.

Se continuar aqui: o seu navegador está bloqueando o JavaScript nesta página. No Tor Browser: clique no escudo, em "Change" e escolha Safer ou Standard. O nível Safest desliga o JavaScript em páginas locais e o painel não consegue arrancar.
